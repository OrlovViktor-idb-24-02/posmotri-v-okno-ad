# Посмотри в окно

CSS для учебного приложения поиска видео из разных городов. Исходная логика JavaScript сохранена. Оформлены формы, карточки видео, загрузка, ошибки и клавиатурный фокус.

Откройте `index.html` в браузере. Для загрузки видео требуется доступ к API Практикума.
